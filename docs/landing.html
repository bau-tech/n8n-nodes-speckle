Why teams add this node

Less plumbing. More building.

Speckle already holds your project's structured truth. n8n already talks to everything else your team uses. This node is the missing two-way pipe between them — built for people who'd rather configure a workflow than maintain a script.

Automate

Retire the manual export

Stop asking someone to open the viewer, export a schedule, and paste it into a spreadsheet. Let a new version trigger the whole reporting chain automatically.

React

Respond the moment a model changes

A dedicated trigger starts your workflow the instant a version lands, a comment is left, or a model updates — no polling, no webhook plumbing to babysit.

Connect

Reach every tool your team already uses

Speckle data becomes just another step in n8n — hand it to Slack, a database, a spreadsheet, an email, or any of the hundreds of apps n8n already speaks to.

Understand

Speaks Revit, IFC, and Tekla — not just geometry

Built for real BIM data, not generic 3D blobs: it reasons about categories, parameters, and element types the way your discipline already does.

Two-way

It doesn't just watch Speckle — it acts on it

Everything above runs in reverse just as easily: a form submission, a database update, or a schedule can create a new project or model, commit a new version, update an object's properties, drop in a comment, or import a file — straight from a workflow, with no direct API calls of your own.

The shape of it

Reads. Writes. Same node, either direction.

Source & target Speckle Projects, models, and versions to read — or a new version, comment, property update, or file import to write.
Orchestration n8n workflow Watches Speckle and acts on it in the same workflow — visually, without custom infrastructure.
Source & target Anywhere Slack, email, spreadsheets, databases, forms, or the next 400+ apps n8n adds — feeding Speckle or fed by it.

Get started

Drop it into any n8n instance

Install it like any other community node — no forked runtime, no separate server to babysit. Point it at a Speckle server, add a personal access token, and start building.

Install npm install n8n-nodes-speckle
Requires n8n · a Speckle server · a personal access token
