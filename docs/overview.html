n8n-nodes-speckle is an open-source community node that exposes the entire Speckle GraphQL API — projects, models, versions, objects, comments, webhooks — as native n8n building blocks, plus a dedicated trigger node that starts a workflow the moment something changes on a Speckle project. Install with npm install n8n-nodes-speckle.

11 resources 1 trigger node GraphQL + REST Revit · Tekla · IFC MIT licensed
What it is

A BIM data platform, made schedulable.

Speckle is the open-source data platform for architecture, engineering, and construction — it stores versioned, structured 3D models and lets any tool (Revit, Rhino, Tekla, IFC pipelines) read and write to the same source of truth over GraphQL. n8n is the workflow-automation canvas that connects that kind of API to everything else a team runs: Slack, spreadsheets, databases, dashboards.

This package is the bridge between them. It wraps 16 GraphQL queries and 27 mutations behind a single node with eleven resources — Project, Model, Version, Object, User, Server, Comment, Webhook, Selection, Viewer, Token — so a BIM workflow becomes a sequence of drag-and-drop steps instead of hand-written API calls. A companion Speckle Trigger node manages its own webhook lifecycle, so a workflow can start itself the instant a new version lands.

General notes

What it buys you

  1. 01 No polling. The Speckle Trigger node creates and tears down its own webhook on activation/deactivation — a new version, comment, or model change starts the workflow directly.
  2. 02 BIM data, flattened. Pull ready-to-chart element tables straight out of Revit, Tekla, and IFC object graphs, with category and parameter filtering built in.
  3. 03 Model analytics on demand. Generate element-count breakdowns — beams, walls, floors, columns — for any version, ready to feed a dashboard node.
  4. 04 Validation as a workflow step. Check objects against an IDS specification or simple property rules, and write corrected values back as a new version automatically.
  5. 05 Cross-server migration. Copy — or export/import as a portable payload — a project, model, or version, full object graph included, between two Speckle servers.
  6. 06 Viewer, embedded. Generate an embeddable link or a ready-made <iframe> for the Speckle 3D viewer, for any project, model, or version.
